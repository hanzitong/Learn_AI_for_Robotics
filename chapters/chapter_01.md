# 第1章　機械学習の数理的基盤

## 概要

機械学習は「データから規則性を学習し，未知の入力に対して予測を行う」計算手続きの総称である．しかし，この直感的な説明の背後には，確率論・線形代数・最適化理論という三つの数学的柱が存在する．本章ではこれらを順に整理し，機械学習を**経験リスク最小化（Empirical Risk Minimization; ERM）**という統一的な枠組みとして定式化する．この枠組みを把握することが，第2章以降で登場するすべてのモデルと学習アルゴリズムを本質的に理解するための前提となる．

---

## 1.1　確率論的基礎

### 1.1.1　確率変数と分布

機械学習においてデータは確率変数の実現値として扱われる．確率変数 $X$ が従う分布を $p(x)$ と書く（連続変数の場合は確率密度関数）．データセット $\mathcal{D} = \{(x_i, y_i)\}_{i=1}^{n}$ は，未知の同時分布 $p(x, y)$ から独立同一分布（i.i.d.）でサンプルされたと仮定することが多い．

期待値は分布 $p$ のもとでの平均であり，

$$\mathbb{E}_{p(x)}[f(x)] = \int f(x)\, p(x)\, dx$$

と定義される．分散は $\mathrm{Var}[X] = \mathbb{E}[(X - \mathbb{E}[X])^2]$ である．

### 1.1.2　条件付き確率とベイズの定理

条件付き確率 $p(y \mid x)$ は，$x$ が与えられたときに $y$ が取る値の分布を記述する．ベイズの定理は，

$$p(y \mid x) = \frac{p(x \mid y)\, p(y)}{p(x)}$$

と表される．ここで $p(y)$ を**事前分布**，$p(x \mid y)$ を**尤度**，$p(y \mid x)$ を**事後分布**と呼ぶ．機械学習における「学習」は，この事後分布を何らかの形で近似することと解釈できる．

### 1.1.3　最尤推定と最大事後確率推定

パラメータ $\theta$ を持つモデルが与えられたとき，**最尤推定（Maximum Likelihood Estimation; MLE）**はデータの対数尤度を最大化するパラメータを求める．教師なし（生成）モデルでは $p(x \mid \theta)$，教師あり（識別）モデルでは $p(y \mid x, \theta)$ を尤度とする：

$$\hat{\theta}_{\mathrm{MLE}} = \arg\max_{\theta} \sum_{i=1}^{n} \log p(y_i \mid x_i, \theta) \quad \text{（識別モデルの場合）}$$

i.i.d. 仮定のもとで対数を取ることで，積の最大化を和の最大化に変換している点が重要である．

事前分布 $p(\theta)$ を組み込んだ**最大事後確率推定（MAP）**は，

$$\hat{\theta}_{\mathrm{MAP}} = \arg\max_{\theta} \left[\sum_{i=1}^{n} \log p(y_i \mid x_i, \theta) + \log p(\theta)\right]$$

となる．MLE はデータ適合を優先し，MAP は事前信念によって過学習を抑制する．$p(\theta) = \mathcal{N}(0, \sigma^2 I)$ という等方ガウス事前分布を仮定すると $\log p(\theta) \propto -\|\theta\|_2^2$ となり，$\ell_2$ 正則化（重み減衰）と等価になる（第4章で詳述）．

### 1.1.4　情報理論的概念

**エントロピー**は分布の不確実性の尺度であり，

$$H(p) = -\sum_{x} p(x) \log p(x)$$

と定義される（連続の場合は積分；機械学習では対数の底として自然対数 $\ln$ を用いることが多く，単位は nats）．**KL ダイバージェンス**は二つの分布 $p$，$q$ の乖離を測り，

$$D_{\mathrm{KL}}(p \| q) = \sum_{x} p(x) \log \frac{p(x)}{q(x)} \geq 0$$

であり，$p = q$ のときのみ $0$ となる．**交差エントロピー**は $H(p, q) = H(p) + D_{\mathrm{KL}}(p \| q)$ と分解でき，分類タスクにおける損失関数として広く使われる．

## 1.2　線形代数の基礎

### 1.2.1　ベクトルと行列

入力データ $x \in \mathbb{R}^d$ は $d$ 次元実ベクトルであり，データセットはしばしば $n \times d$ の行列 $X$ としてまとめられる．行列積，転置，逆行列，行列式といった基本演算は，ニューラルネットワークの順伝播計算（第2章）や共分散行列の解析で繰り返し現れる．

### 1.2.2　ノルムと距離

ベクトルの大きさを測る**ノルム**として，

- $\ell_1$ ノルム：$\|x\|_1 = \sum_i |x_i|$
- $\ell_2$ ノルム（ユークリッドノルム）：$\|x\|_2 = \sqrt{\sum_i x_i^2}$
- $\ell_\infty$ ノルム：$\|x\|_\infty = \max_i |x_i|$

が用いられる．ノルムは正則化項（重み減衰，スパース制約）の設計に直接対応する．

### 1.2.3　固有値分解と特異値分解

対称行列 $A \in \mathbb{R}^{d \times d}$ は**固有値分解** $A = Q \Lambda Q^\top$（$Q$：直交行列，$\Lambda$：固有値の対角行列）を持つ．任意の行列 $M \in \mathbb{R}^{m \times n}$ に対しては**特異値分解（SVD）** $M = U \Sigma V^\top$ が存在し，次元削減（主成分分析）や行列近似に応用される．機械学習においては，損失曲面のヘッセ行列の固有値スペクトルが最適化の難易度を特徴づける重要な量である．

### 1.2.4　勾配と微分

スカラー値関数 $f: \mathbb{R}^d \to \mathbb{R}$ のパラメータ $\theta$ に関する**勾配**は，

$$\nabla_\theta f(\theta) = \left(\frac{\partial f}{\partial \theta_1}, \frac{\partial f}{\partial \theta_2}, \ldots, \frac{\partial f}{\partial \theta_d}\right)^\top \in \mathbb{R}^d$$

であり，勾配の方向が $f$ の最急上昇方向を示す．ヤコビアン行列（ベクトル値関数の一階微分）とヘッセ行列（スカラー値関数の二階微分）はパラメータ更新の解析に用いられる．

## 1.3　最適化理論

### 1.3.1　最小化問題の定式化

機械学習の学習過程は，パラメータ $\theta$ に関する目的関数 $\mathcal{L}(\theta)$（損失関数）の最小化として定式化される：

$$\hat{\theta} = \arg\min_{\theta} \mathcal{L}(\theta)$$

一般に $\mathcal{L}$ は非凸であり，大域的最適解の発見は保証されない．実用上は局所最適解に収束させることを目標とする．

### 1.3.2　凸性と最適化の難易度

関数 $f$ が**凸関数**であるとは，任意の $\theta_1, \theta_2$ と $\lambda \in [0,1]$ に対して

$$f(\lambda \theta_1 + (1-\lambda)\theta_2) \leq \lambda f(\theta_1) + (1-\lambda) f(\theta_2)$$

が成立することである．凸関数の最小化問題では，局所最適解は大域最適解でもある．線形回帰の最小二乗損失は凸であるが，深層ニューラルネットワークの損失は一般に非凸である．高次元パラメータ空間では真の局所最適解よりも**鞍点（saddle point）**が支配的であり（Dauphin et al., 2014），また十分に過パラメータ化されたネットワークでは良性の損失曲面構造が生じることが知られている（Du et al., 2019）．実用上，SGD は鞍点を脱出する暗黙の正則化効果を持つ．

### 1.3.3　勾配降下法

最も基本的な最適化アルゴリズムである**勾配降下法（Gradient Descent; GD）**は，

$$\theta_{t+1} \leftarrow \theta_t - \eta \nabla_\theta \mathcal{L}(\theta_t)$$

によってパラメータを反復更新する（$\eta > 0$：学習率）．学習率が大きすぎると発散し，小さすぎると収束が遅くなる．ニューラルネットワークの学習では全データを使った GD は計算コストが高く，ミニバッチ SGD が用いられる（詳細は第3章）．

### 1.3.4　ラグランジュ乗数法と制約付き最適化

等式制約 $g(\theta) = 0$ のある最適化問題は，**ラグランジュ関数**

$$\mathcal{L}(\theta, \lambda) = f(\theta) + \lambda g(\theta)$$

の停留点を求めることで解ける．不等式制約を含む場合は KKT 条件が必要である．サポートベクターマシン（SVM）は制約付き最適化として定式化され，カーネル法と組み合わさることで非線形分類を実現する．

## 1.4　損失関数の設計

### 1.4.1　回帰タスクの損失関数

入力 $x$ から連続値 $y \in \mathbb{R}$ を予測する回帰タスクでは，**平均二乗誤差（MSE）**が最も基本的な損失関数である：

$$\mathcal{L}_{\mathrm{MSE}}(\theta) = \frac{1}{n} \sum_{i=1}^{n} (y_i - f_\theta(x_i))^2$$

MSE はガウスノイズの仮定のもとで MLE から自然に導出される：目標 $y$ が $y = f_\theta(x) + \epsilon$，$\epsilon \sim \mathcal{N}(0, \sigma^2)$ で生成されると仮定すると，$-\log p(y \mid x, \theta) \propto (y - f_\theta(x))^2$ となり，MLE が MSE 最小化と等価になる．外れ値に対してロバストな**平均絶対誤差（MAE）**（ラプラス分布の MLE に対応）や，両者を折衷した**Huber 損失**も用いられる．

### 1.4.2　分類タスクの損失関数とソフトマックス

クラス $k \in \{1, \ldots, K\}$ の分類タスクでは，ネットワーク最終層が出力するロジット $z \in \mathbb{R}^K$ を確率分布に変換するために**ソフトマックス関数**を用いる：

$$\hat{p}_\theta(k \mid x) = \frac{\exp(z_k)}{\sum_{j=1}^{K} \exp(z_j)}$$

ソフトマックスは各出力を $(0, 1)$ に収め，和が $1$ になることを保証する．この出力と真のラベルの one-hot 分布との間の**交差エントロピー損失**が標準的な目的関数である：

$$\mathcal{L}_{\mathrm{CE}}(\theta) = -\frac{1}{n} \sum_{i=1}^{n} \sum_{k=1}^{K} \mathbb{1}[y_i = k] \log \hat{p}_\theta(k \mid x_i) = -\frac{1}{n} \sum_{i=1}^{n} \log \hat{p}_\theta(y_i \mid x_i)$$

これはカテゴリ分布のもとでの MLE と等価である．二値分類では出力をシグモイド関数 $\sigma(z) = 1/(1+e^{-z})$ で変換し，**バイナリ交差エントロピー**（BCE）を用いる．

### 1.4.3　KL ダイバージェンスと変分推論

分布間の乖離を最小化する問題は変分推論（Variational Inference）として定式化され，VAE（Variational Autoencoder）や拡散モデル（第10章）の目的関数の基礎となる．変分下界（ELBO: Evidence Lower Bound）は，

$$\log p(x) \geq \mathbb{E}_{q(z|x)}[\log p(x|z)] - D_{\mathrm{KL}}(q(z|x) \| p(z))$$

と表され，右辺の最大化が学習目標となる．

## 1.5　経験リスク最小化（ERM）

### 1.5.1　リスクと経験リスク

未知の真の分布 $p(x, y)$ に対して，予測関数 $f_\theta$ の**真のリスク（汎化誤差）**は，

$$R(\theta) = \mathbb{E}_{(x,y) \sim p}[\ell(f_\theta(x), y)]$$

と定義される（$\ell$：損失関数）．真の分布は未知のため $R(\theta)$ は直接最小化できない．そこで，有限データセット $\mathcal{D}$ 上の平均として**経験リスク**を定義し，

$$\hat{R}(\theta) = \frac{1}{n} \sum_{i=1}^{n} \ell(f_\theta(x_i), y_i)$$

この $\hat{R}(\theta)$ を最小化するのが ERM の原理である．大数の法則により，固定した $\theta$ に対して $n \to \infty$ で $\hat{R}(\theta) \to R(\theta)$ が保証される．しかし ERM の最小化ではパラメータ $\hat{\theta}$ がデータに依存して変化するため，**一様収束**（仮説クラス $\mathcal{F}$ 全体にわたる同時収束）が必要になる．この要請が PAC（Probably Approximately Correct）学習理論の出発点であり，有限サンプルでの一般化を保証するためには仮説クラスの複雑度（VC次元や Rademacher 複雑度）が有限である必要がある（第4章で詳述）．

### 1.5.2　帰納バイアスと仮説クラス

ERM は**仮説クラス** $\mathcal{F}$（モデルが表現できる関数の集合）の中から最適な $f_\theta$ を選択する：

$$\hat{f} = \arg\min_{f \in \mathcal{F}} \hat{R}(f)$$

仮説クラスの選択がモデルの**帰納バイアス（inductive bias）**を決定する．たとえば線形モデルは線形関数クラスを，CNN は空間的局所性を，Transformer は全域的な依存関係を仮説クラスとして内包している．帰納バイアスはタスクの構造的仮定と一致させることで，汎化性能を向上させる．

## まとめ

本章で学んだ数理的枠組みを整理する：

| 概念 | 役割 |
|------|------|
| 確率・ベイズの定理 | 不確実性の定量化，モデルの確率的解釈 |
| MLE / MAP | 損失関数の導出，正則化の理論的根拠 |
| KL ダイバージェンス | 分布間の乖離，生成モデルの目的関数 |
| 線形代数・勾配 | パラメータ更新の計算，損失曲面の解析 |
| ERM | 学習問題の統一的定式化 |
| 帰納バイアス | アーキテクチャ選択の設計原理 |

これらの概念は，以降の全章を貫く共通言語である．次章ではこの枠組みの上に，ニューラルネットワークという具体的なモデルクラスを構築する．
