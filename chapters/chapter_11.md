# 第11章　マルチモーダル学習と視覚・言語表現の統合

## 概要

人間はテキスト・画像・音声・点群など複数のモダリティを統合して世界を理解する．**マルチモーダル学習（Multimodal Learning）**は，複数のモダリティを処理・統合するモデルを構築する分野である．特に視覚と言語の統合（**Vision-Language Models; VLM**）は，ロボット知能への道を開く中心技術となっている：テキストで指示を与え，カメラ画像を見て，適切な行動を出力する VLA（第13章）の基盤がここにある．本章では，対照学習による視覚・言語表現の統合（CLIP），クロスアテンションによるマルチモーダル Transformer，3D 点群のトークン化，および VLM のアーキテクチャを体系的に論じる．

---

## 11.1　モダリティの特性と統合の課題

### 11.1.1　モダリティ間の異質性

異なるモダリティは根本的に異なる構造を持つ：

| モダリティ | データ構造 | 空間/時間的特性 | 典型的な表現 |
|-----------|-----------|---------------|------------|
| テキスト | 離散トークン列 | 系列的 | 埋め込みベクトル |
| 画像 | 連続ピクセルグリッド | 空間的 | CNN 特徴 / パッチ埋め込み |
| 音声 | 連続波形 / スペクトル | 時空間的 | スペクトログラム埋め込み |
| 3D 点群 | 不規則な3D点集合 | 空間的（非グリッド） | PointNet 埋め込み |
| 力覚センサ | 連続時系列 | 時系列 | 1D CNN / Transformer |

異なるモダリティを「共通の潜在空間」に埋め込むことが，マルチモーダル学習の中心目標である．

### 11.1.2　統合の三つのアプローチ

1. **早期融合（Early Fusion）：** 入力レベルで異なるモダリティを連結してから処理
2. **後期融合（Late Fusion）：** 各モダリティを独立に処理してから出力レベルで統合
3. **中間融合（Intermediate Fusion）：** 各モダリティの中間表現を Transformer のクロスアテンション等で統合（現代の主流）

## 11.2　CLIP：対照的な視覚・言語学習

### 11.2.1　CLIP の設計

**CLIP（Contrastive Language-Image Pretraining）**（Radford et al., 2021）は，インターネット上から収集した 4 億対の（画像，テキスト）ペアを対照学習で学習することで，テキストと画像を統一潜在空間に埋め込む：

- **画像エンコーダ** $f$：ResNet または ViT を使用，画像 $I$ を埋め込みベクトル $z_I = f(I) / \|f(I)\|_2$ に変換
- **テキストエンコーダ** $g$：Transformer を使用，テキスト $T$ を埋め込みベクトル $z_T = g(T) / \|g(T)\|_2$ に変換

### 11.2.2　対照学習目標

バッチサイズ $N$ の（画像，テキスト）ペアに対して，$N$ 個の正例ペアと $N^2 - N$ 個の負例ペアをもつ**対称クロスエントロピー損失**を最小化する：

$$\mathcal{L}_{\mathrm{CLIP}} = -\frac{1}{2N}\left(\underbrace{\sum_{i=1}^{N}\log \frac{\exp(\mathrm{sim}(z_{I_i}, z_{T_i})/\tau)}{\sum_{j=1}^{N}\exp(\mathrm{sim}(z_{I_i}, z_{T_j})/\tau)}}_{\text{画像→テキスト方向}} + \underbrace{\sum_{i=1}^{N}\log \frac{\exp(\mathrm{sim}(z_{T_i}, z_{I_i})/\tau)}{\sum_{j=1}^{N}\exp(\mathrm{sim}(z_{T_i}, z_{I_j})/\tau)}}_{\text{テキスト→画像方向}}\right)$$

$\tau$：学習可能な温度パラメータ，$\mathrm{sim}$：コサイン類似度．

このスケーラブルな対称損失は，「対応する画像とテキストの埋め込みを近づけ，無関係な対を遠ざける」共通潜在空間を形成する．

### 11.2.3　CLIP の能力

**Zero-Shot 転移：** CLIP はクラスラベルをテキストとして表現し（例：「a photo of a [class]」），$\arg\max_{c} \mathrm{sim}(z_I, z_{T_c})$ でゼロショット分類を実現する．ImageNet でのゼロショット精度は ResNet-50 の教師あり学習と同等．

**Open-Vocabulary 理解：** 固定クラス集合に縛られず，任意のテキスト記述に対して画像を評価できる．

**SigLIP**（Zhai et al., 2023）は CLIP の損失をシグモイドベースに変更することで，負例の影響を分離し，小バッチでの学習効率を改善している．OpenVLA，π0 等のロボットモデルで使用される．

## 11.3　大規模マルチモーダル Transformer

### 11.3.1　LLaVA アーキテクチャ

**LLaVA（Large Language and Vision Assistant）**（Liu et al., 2023）は最もシンプルかつ強力な VLM アーキテクチャの一つ：

1. **ビジョンエンコーダ**（CLIP ViT）で画像を特徴ベクトル列に変換
2. 線形投影（MLP）で視覚特徴の次元を LLM の入力次元に合わせる（**ビジョン-言語プロジェクタ**）
3. 視覚トークンとテキストトークンを連結して LLM に入力

$$\text{Input to LLM} = [\underbrace{z_{v,1}, z_{v,2}, \ldots, z_{v,N_v}}_{\text{視覚トークン}}, \underbrace{x_1, x_2, \ldots, x_T}_{\text{テキストトークン}}]$$

学習は2段階：
1. **事前学習（Alignment）：** ビジョン-言語プロジェクタのみを学習（画像キャプション）
2. **指示チューニング：** 全パラメータを学習（視覚質問応答，多モーダル対話）

### 11.3.2　Flamingo と In-Context Vision-Language Learning

**Flamingo**（Alayrac et al., 2022）は，事前学習済み LLM と視覚エンコーダを**クロスアテンション**で疎に結合することで，数ショットの視覚言語タスクを可能にした：

- 事前学習済みビジョンエンコーダと LLM のパラメータを**固定**
- Perceiver Resampler で視覚特徴を固定数のトークンに圧縮
- LLM の各 Transformer 層の間にクロスアテンション層を挿入（新規パラメータ）

この設計は，大規模な事前学習済みモデルを比較的少ない追加パラメータで視覚理解に拡張できることを示した．

### 11.3.3　PaliGemma / InternVL

現代の VLM は CLIP ViT + 大規模 LLM の組み合わせが主流：

- **PaliGemma**（Beyer et al., 2024）：SigLIP ViT + Gemma LLM；シンプルな設計でロボット系（π0 等）で広く使用
- **InternVL2**（Chen et al., 2024）：InternViT + InternLM；動的解像度対応で高解像度画像に強い

## 11.4　3D 点群の処理

### 11.4.1　点群の特性と課題

ロボットは LiDAR・深度カメラ（RealSense，Structure Sensor など）から3次元点群 $\{p_i\}_{i=1}^{N} \subset \mathbb{R}^3$（または RGB-D の場合 $\mathbb{R}^6$）を取得する．点群は：

- **不規則（irregular）：** グリッドではなくランダムな点の集合
- **順序不変（permutation invariant）：** 点のインデックスに意味がない
- **疎（sparse）：** 空間の大部分が空白

これらの性質は，CNN や通常の Transformer の直接適用を困難にする．

### 11.4.2　PointNet とその発展

**PointNet**（Qi et al., 2017）は，点群処理の基礎的なアーキテクチャ：

1. 各点を独立に MLP で高次元特徴に変換
2. **対称関数（max pooling）**で全点の特徴を集約 → 順序不変性を保証
3. グローバル特徴から分類・セグメンテーションを出力

$$f(\{p_1, \ldots, p_N\}) = g\left(\max_{i=1}^{N}h(p_i)\right)$$

$h$：共有 MLP，$\max$：次元ごとの最大値，$g$：タスクヘッド．

**PointNet++**（Qi et al., 2017b）：局所近傍点のグループ化と階層的特徴抽出により，局所的な幾何学構造を学習する．

### 11.4.3　点群の Transformer：Point Transformer

**Point Transformer**（Zhao et al., 2021）は，局所近傍内での自己注意により点群特徴を抽出する：

$$y_i = \sum_{x_j \in \mathcal{N}(x_i)} \rho(W_\gamma(\varphi(x_i) - \psi(x_j)) + \delta) \odot (W_\alpha x_j + \delta)$$

$\varphi$，$\psi$：点特徴の線形変換，$\delta = \theta(p_i - p_j)$：相対位置エンコーディング，$\rho$：Softmax 正規化，$W_\gamma$：位置的注意重みの計算．

### 11.4.4　トークン化による大規模モデルとの統合

ロボット基盤モデルやVLAで点群を扱う際の主なアプローチ：

1. **ボクセル化→CNN → トークン化：** 3D 空間をボクセルグリッドに変換して CNN または 3D Transformer で処理
2. **FPS（最遠点サンプリング）+ PointNet++ → トークン化：** 代表点のサンプリングと局所特徴集約でトークンを生成
3. **深度画像 → ViT：** 点群を深度マップや RGB-D 画像に変換して ViT で処理（最も実装が簡単）

## 11.5　対照学習の発展とロボットへの応用

### 11.5.1　DINO / DINOv2

**DINO**（Caron et al., 2021）は自己教師あり学習で ViT 特徴の局所的なセマンティクスを学習する：Student-Teacher 蒸留フレームワークで，同一画像の異なるクロップを正例として学習する．教師ネットワークはモメンタム更新（EMA）．

**DINOv2**（Oquab et al., 2023）は大規模データ（LVD-142M，厳選された1億4千万枚）で事前学習した汎用ビジョンエンコーダ：深度推定・セグメンテーション・ロボット操作の視覚表現として広く使われる．

### 11.5.2　ロボット知覚への応用

| モデル | 用途 |
|-------|------|
| CLIP / SigLIP | 言語条件付き物体認識，ゴール条件付け |
| DINOv2 | 汎用的なロボット視覚特徴，深度推定 |
| ViT（LLaVA 等） | VLA のビジョンバックボーン |
| PointNet++ | LiDAR 点群での障害物検知，把持計画 |

## まとめ

| 概念 | 内容 |
|------|------|
| CLIP | 4 億ペアの対照学習；テキスト・画像を共通潜在空間に統合 |
| VLM（LLaVA） | ビジョンエンコーダ + プロジェクタ + LLM；視覚言語タスクを統合 |
| クロスアテンション | 異なるモダリティ間の動的な情報統合機構 |
| PointNet / Point Transformer | 不規則な3D点群の順序不変な特徴抽出 |
| DINOv2 | 汎用ビジョン特徴；ロボット知覚の基盤 |

次章では，これらの視覚・言語表現をロボット制御に直接つなぐ**模倣学習と行動表現**を詳述する．
