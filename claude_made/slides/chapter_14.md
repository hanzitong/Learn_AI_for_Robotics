# 第14章　ロボット基盤モデルと Sim-to-Real 転移

**大規模事前学習と多様なデータにより，少量のファインチューニングで新タスクに適応する汎用ロボット知能を実現する**

---

## ロボット基盤モデルは「多形態・多タスク・多環境」への汎化を目標とする

NLP の GPT-3，視覚の DINOv2 と同様に，**大規模事前学習 + 少量ファインチューニング**を目指す：

| 汎化の種類 | 内容 |
|-----------|------|
| タスク汎化 | 把持・押す・引く・組み立てなどを単一モデルで |
| 形態汎化 | 異なるアーム，ハンド，モバイルロボット，二足歩行への適応 |
| 環境汎化 | 異なる照明・背景・物体配置・カメラ位置への頑健性 |
| 指示汎化 | 言語・ゴール画像・デモビデオなど多様な指定への対応 |

---

## スケーリングの「モデル・データ・多様性」の三軸が基盤モデルの能力を高める

1. **モデルサイズ：** パラメータ数の増加（数百万 → 数十億）
2. **データ量：** デモンストレーション数の増加（数千 → 数百万軌跡）
3. **データ多様性：** タスク・ロボット形態・環境の多様性の増加

- LLM と同様のスケーリング則がロボティクスでも観察されている（RT-X）
- **ボトルネック：** 実機ロボットデータの収集コストが高く，データ量の拡大が困難

---

## Open X-Embodiment は 22 形態・100 万軌跡以上を統一フォーマットで提供する

- **規模：** 約 22 種類のロボット形態，60 以上のデータセット，100 万以上の軌跡
- **RLDS（Robot Learning Dataset Specification）** 形式で統一 → 異なるロボットのデータを共通フォーマットで提供
- **異質性の課題：**
  - 行動空間：関節角度次元・制御周波数・座標系が異なる → ロボット ID でコンディショニング
  - 観測：カメラ解像度・視点の差異 → 前処理で吸収
- **Cross-Embodiment 学習：** 異なる形態のデータ混合学習 → 単一形態のみより汎化が向上

---

## シミュレーションは実機の 100〜1000 倍の速度でデータを収集できる

| 利点 | 内容 |
|------|------|
| 高速・並列収集 | 実機比 100〜1000 倍 |
| 安全なリセット | 落下・衝突による破損なし |
| 完全な状態観測 | ground truth の位置・力が利用可能 |
| 自動タスク判定 | 報酬計算の自動化 |

代表的な物理シミュレータ：MuJoCo（高精度物理），Isaac Gym（GPU 並列，数千環境同時実行）

---

## Sim-to-Real Gap は視覚・物理・動力学・センサの4種類の乖離から生じる

| 乖離の種類 | 内容 | 例 |
|-----------|------|-----|
| 視覚的乖離 | テクスチャ・照明・カメラノイズの違い | シム：完全照明，実機：影・反射 |
| 物理的乖離 | 摩擦・剛性・質量の違い | シム：理想把持，実機：摩擦ばらつき |
| 動力学的乖離 | モータ遅延・バックラッシュ | 制御の追従誤差 |
| センサ乖離 | ノイズ・キャリブレーション誤差 | 深度センサのノイズ |

---

## ドメインランダム化はシミュレーションパラメータを意図的に乱して実機への頑健性を獲得する

$$\pi = \arg\max_\pi \mathbb{E}_{\xi \sim p(\Xi)}\!\left[J(\pi, \xi)\right]$$

$\xi$：ランダム化パラメータ（物理・視覚特性），$p(\Xi)$：ランダム化分布

- **視覚的ランダム化：** テクスチャ・照明・カメラ視点・FOV・ノイズ
- **物理的ランダム化：** 質量・摩擦係数・アクチュエータゲイン・遅延
- OpenAI の Dexterous Manipulation（2019）：ドメインランダム化のみで実機デキスタラスハンド操作への転移を達成

---

## ADR は成功率に応じてランダム化範囲を自動調整する適応的カリキュラムである

**ADR（Adaptive Domain Randomization；Akkaya et al., 2019）：**

```
成功率が十分高い → ランダム化範囲を拡大（難易度を上げる）
成功率が低い    → ランダム化範囲を縮小（難易度を下げる）
```

- 固定 DR と比較して少ない試行で実機転移を達成
- **システム識別（System ID）：** 実機データからシミュレーションパラメータを推定して Gap を縮小
- **RMA（Rapid Motor Adaptation）：** オンラインで環境パラメータを適応する学習済みモジュール → 脚ロボットの実機転移に成功

---

## LLM とシミュレーターの組み合わせにより，タスクとデモを自動生成できる

- **GenSim（Katara et al., 2023）：** LLM が新タスク記述・シミュレーション設定・評価コードを生成 → シミュレータ上でデモを自動収集
- **ビデオからの学習：** YouTube の人間の手の動作から軌跡推定 → ロボット行動に変換（Retargeting）
- **RoboCat：** ロボットが新タスクを自律的に試行し，成功軌跡を自己追加する自己改善ループ

---

## まとめ：ロボット基盤モデルの設計原理

| 概念 | 内容 |
|------|------|
| ロボット基盤モデル | 多形態・多タスク・大規模事前学習 + 少量ファインチューニング |
| Open X-Embodiment | 22 形態・60+ データセット・100 万+ 軌跡 |
| ドメインランダム化 | シム内でパラメータをランダム化 → 実機への頑健性 |
| ADR | 成功率に応じて難易度を自動調整 |
| システム識別 | 実機データからシミュレーションパラメータを推定 |
| 自動データ生成 | LLM + シミュレータでタスクとデモを自動生成 |
