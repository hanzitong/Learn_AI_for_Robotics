# 第14章　ロボット基盤モデルと Sim-to-Real 転移

## 概要

第13章では VLA の設計を論じた．本章では，VLA をさらに大規模化・汎化させた**ロボット基盤モデル（Robot Foundation Model）**の設計原理と，その学習・展開に不可欠な **Sim-to-Real 転移**（シミュレーションから実機への転移）技術を詳述する．ロボット基盤モデルは「多形態・多タスク・多環境」への汎化を目指し，大量の多様なデータで事前学習することで，少量のファインチューニングで新しいタスクに適応できる汎用ロボット知能を実現しようとしている．

---

## 14.1　ロボット基盤モデルの設計原理

### 14.1.1　基盤モデルとしてのロボット学習

NLP における GPT-3，視覚における DINOv2 が示したように，**大規模事前学習＋少量ファインチューニング**のパラダイムはロボティクスにも適用できる．ロボット基盤モデルは以下を目指す：

- **タスク汎化：** 把持・押す・引く・組み立てなど，多様な操作タスクを単一モデルで実行
- **形態汎化：** 異なるロボットアーム，ハンド構成，モバイルロボット，二足歩行ロボットへの適応
- **環境汎化：** 異なる照明・背景・物体配置・カメラ位置への頑健性
- **指示汎化：** 自然言語・ゴール画像・デモビデオなど多様な指定方法への対応

### 14.1.2　スケーリングの三軸

ロボット基盤モデルの能力はスケーリングの三つの軸に沿って向上することが経験的に示されている：

1. **モデルサイズ：** パラメータ数の増加（数百万→数十億）
2. **データ量：** デモンストレーション数の増加（数千→数百万軌跡）
3. **データ多様性：** タスク・ロボット・環境の多様性の増加

スケーリングの効果はロボティクスでも LLM と同様に観察されているが（RT-X 等），データ収集コストの高さがボトルネックとなっている．

---

## 14.2　Open X-Embodiment

### 14.2.1　データセットの概要

**Open X-Embodiment（OXE）**（Open X-Embodiment Collaboration, 2023）は，ロボット学習コミュニティが協力して作成した大規模な多形態・多タスクデータセット：

- **規模：** 約 22 種類のロボット形態，60 以上のデータセット，100 万以上のデモンストレーション軌跡
- **多様性：** テーブルトップ操作，モバイルマニピュレーション，二足歩行ロボット
- **データ形式の統一：** RLDS（Robot Learning Dataset Specification）形式で統一し，異なるロボットのデータを共通フォーマットで提供

### 14.2.2　データの異質性と統合

異なるロボット・データセット間の行動空間・観測空間・タスク形式の違いは，統合学習の主要な技術的課題：

- **行動空間の統一：** 各ロボット固有の行動（関節角度次元，制御周波数，座標系）を正規化またはロボット ID でコンディショニング
- **観測のアライメント：** カメラ解像度・視点・フレームレートの差異を前処理で吸収
- **タスク記述の統一：** 自然言語によるタスク記述を全データに付与

### 14.2.3　Cross-Embodiment 学習

異なる形態のロボットデータを混合して学習することで，単一形態データのみでの学習を超えた汎化が得られることが示された（RT-X）．

一種の**転移学習**として解釈できる：あるロボット形態でのタスク知識（物理的な接触の理解，物体の把握方法など）が，他の形態のロボットへの学習を補助する．

## 14.3　シミュレーションを活用した大規模学習

### 14.3.1　シミュレーションの利点と課題

実機ロボットでのデータ収集の限界（コスト・速度・安全性）を克服するために，**物理シミュレータ**でのデータ収集が広く活用される：

**利点：**
- 高速・並列な大量データ収集（実機比 100〜1000 倍以上）
- 安全なリセットが可能（落下・衝突による破損なし）
- 完全な状態観測（ground truth の位置・力が利用可能）
- 自動的なタスク成功判定（報酬計算の自動化）

**課題：**
- **Sim-to-Real Gap：** シミュレーションと実機の外観・物理特性の乖離 → 実機で性能低下

代表的な物理シミュレータ：
- **MuJoCo**（Todorov et al., 2012）：筋骨格系・ソフト材料も含む高精度物理；DeepMind Control Suite等で標準
- **Isaac Gym / Isaac Lab**（NVIDIA）：GPU 並列で数千環境を同時実行；強化学習のスケールアップに特化
- **PyBullet / Sapien / Pybullet-UR5：** オープンソースの物理シミュレーション

### 14.3.2　合成データによる視覚的学習

物理シミュレーションに加え，**3D グラフィックスレンダリング**（PhotoRealistic Rendering）により視覚的に現実に近い画像を大量生成できる：

- **NVIDIA Omniverse / Isaac Sim：** リアルタイムレイトレーシングによる高品質レンダリング
- **Habitat（Meta）：** リアルな室内環境でのナビゲーション・操作学習
- **RoboAgent / GenSim：** LLM と生成モデルを使って新しいタスクと対応するデータを自動生成

## 14.4　Sim-to-Real 転移技術

### 14.4.1　Sim-to-Real Gap の種類

シミュレーションと実機の主要な乖離：

| 乖離の種類 | 内容 | 例 |
|-----------|------|-----|
| 視覚的乖離 | テクスチャ・照明・カメラノイズの違い | シム：完全な照明，実機：影・反射 |
| 物理的乖離 | 摩擦・剛性・質量の違い | シム：理想的な把持，実機：摩擦ばらつき |
| 動力学的乖離 | モータ遅延・バックラッシュ | 制御の追従誤差 |
| センサ乖離 | ノイズ・キャリブレーション誤差 | 深度センサのノイズ |

### 14.4.2　ドメインランダム化（Domain Randomization）

**ドメインランダム化（DR）**（Tobin et al., 2017；Andrychowicz et al., 2020）は，シミュレーションのパラメータをランダムに変動させることで，学習されたモデルが広いパラメータ分布に頑健になるように訓練する：

$$\pi = \arg\max_\pi \mathbb{E}_{\xi \sim p(\Xi)}\left[J(\pi, \xi)\right]$$

$\xi$：ランダム化パラメータ（物理・視覚特性），$p(\Xi)$：ランダム化分布

**視覚的ランダム化：**
- テクスチャ：ランダムな色・模様・画像テクスチャ
- 照明：光源位置・強度・色温度
- カメラ：視点・FOV・ノイズ・歪み

**物理的ランダム化：**
- 質量・慣性モーメント
- 摩擦係数（静止・動的）
- アクチュエータゲイン・遅延

**Dexterous Manipulation**（OpenAI, 2019）はドメインランダム化のみで実機デキスタラスハンド操作への転移を達成した先駆的な実証．

### 14.4.3　アダプティブドメインランダム化（ADR）

固定のランダム化範囲ではなく，**モデルの性能に応じてランダム化の幅を自動調整**するアダプティブ手法（Akkaya et al., 2019）：

```
難易度を徐々に上げる自動カリキュラム:
成功率が十分高い → ランダム化範囲を拡大
成功率が低い → ランダム化範囲を縮小
```

ADR により，固定 DR より少ない試行で実機への転移が達成できる．

### 14.4.4　システム識別とアダプテーション

より高精度なシミュレーションを実現するために，実機データからシミュレーションパラメータを推定する**システム識別（System Identification）**：

$$\xi^* = \arg\min_\xi \sum_{t} \|\hat{s}_{t+1}(\xi) - s_{t+1}^{\mathrm{real}}\|^2$$

$\hat{s}_{t+1}(\xi)$：シミュレーションの予測状態（パラメータ $\xi$ のもと），$s_{t+1}^{\mathrm{real}}$：実機の観測状態．

**RMA（Rapid Motor Adaptation）**（Kumar et al., 2021）は，オンラインで環境パラメータ（terrain 特性，摩擦）を推定する適応モジュールを学習し，脚ロボットの実機転移に成功した．

### 14.4.5　リアルタイムアダプテーション

実機環境でのオンライン適応：

- **MAML（Model-Agnostic Meta-Learning）：** 少数の実機ステップで新しい環境に適応するメタ学習
- **Online Fine-Tuning：** 実機での失敗経験から継続的にモデルを更新
- **Residual Policy：** シミュレーションで学習した方策 $\pi_{\mathrm{sim}}$ に対する残差 $\delta\pi$ を実機データで学習

## 14.5　データ生成の自動化

### 14.5.1　自動タスク生成

人間がタスクを設計するコストを削減するために，**LLM と物理シミュレーションを組み合わせた自動データ生成**が進んでいる：

- **GenSim**（Katara et al., 2023）：LLM が新しいタスク記述・シミュレーション設定・評価コードを生成し，シミュレータ上でデモンストレーションを自動収集
- **GROOT**：VLM を使って物体の把持点・配置目標を視覚的に決定し，タスクを自動生成

### 14.5.2　ビデオからの学習

テレオペレーションデータの収集コストを削減するために，**人間の手の動作ビデオ**（YouTube 等）から模倣学習する手法が研究されている：

- 人間の手と物体のポーズ推定（e.g., DINO-WM, Videos in the Wild）
- 推定した動作軌跡をロボット行動に変換（Retargeting）
- ビデオから視覚的な表現や報酬関数を抽出（R3M, VIP）

### 14.5.3　ロボットが自律的にデータを収集する

**自律的探索（Autonomous Exploration）**により，人間の監督なしにロボットが自ら環境と相互作用してデータを収集する：

- **RoboCat**（Bousmalis et al., 2023）：ロボットが新しいタスクを自律的に試行し，成功軌跡をデータセットに追加する自己改善ループ
- **GRAPE**：拡散モデルを使ってロボットが実行可能な新しいスキルを生成

## 14.6　評価と安全性

### 14.6.1　基盤モデルの評価プロトコル

ロボット基盤モデルの汎化能力を評価するための標準的なプロトコル：

- **LIBERO**（Liu et al., 2023）：4 つの汎化軸（目標・空間・物体・タスク）でモデルを系統的に評価するベンチマーク
- **SIMPLER**（Li et al., 2024）：実機評価とシミュレーション評価の相関を検証するシミュレーション評価環境
- **BridgeData V2**（Walke et al., 2023）：異なる手法の汎用的な評価のための実機データセット

### 14.6.2　安全性の考慮

実環境でのロボット展開における安全性：

- **実行時モニタリング：** 異常検知（力・位置の急変）による自動停止
- **保守的な行動領域（Safe Operating Region）：** 事前に定義した安全領域外への動作を制限
- **不確実性推定：** モデルの予測不確実性が高い場合に人間に委譲
