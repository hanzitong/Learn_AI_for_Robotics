# 第4章　汎化理論と正則化技術

## 概要

機械学習の最終目標は，訓練データへの適合（経験リスクの最小化）ではなく，未知のテストデータへの予測精度（真のリスクの最小化）である．しかし，十分に複雑なモデルは訓練データに過剰適合（**過学習**）し，真のリスクが経験リスクを大きく上回るようになる．本章では，(1) 汎化誤差を理論的に定式化する**バイアス・バリアンス分解**と**PAC学習理論**，(2) 過学習を抑制するための**正則化技術**（$\ell_1/\ell_2$ 正則化，Dropout，バッチ正規化，データ拡張）を体系的に論じる．

---

## 4.1　バイアス・バリアンス分解

### 4.1.1　汎化誤差の分解

真のリスク（汎化誤差）をバイアスとバリアンスに分解することで，モデルの複雑度と汎化の関係を定量的に理解できる．

回帰タスクにおいて，真の関数 $f^*(x)$ と，サイズ $n$ の訓練データセット $\mathcal{D}$ から学習したモデル $\hat{f}(x; \mathcal{D})$ を考える．入力 $x$ における予測の期待二乗誤差は，

$$\mathbb{E}_{\mathcal{D}}[(f^*(x) - \hat{f}(x;\mathcal{D}))^2] = \underbrace{\left(\mathbb{E}_{\mathcal{D}}[\hat{f}(x;\mathcal{D})] - f^*(x)\right)^2}_{\text{Bias}^2} + \underbrace{\mathbb{E}_{\mathcal{D}}\left[\left(\hat{f}(x;\mathcal{D}) - \mathbb{E}_{\mathcal{D}}[\hat{f}(x;\mathcal{D})]\right)^2\right]}_{\text{Variance}}$$

と分解される．（観測ノイズ $\sigma_\varepsilon^2$ がある場合はさらに Noise 項が加わる．）

- **バイアス（Bias）：** モデルクラスが真の関数 $f^*$ を表現できないことによる系統的な誤差．モデルが単純すぎるとバイアスが大きくなる（**過小適合 / underfitting**）．
- **バリアンス（Variance）：** 訓練データセットの変動に対するモデルの感度．モデルが複雑すぎるとバリアンスが大きくなる（**過学習 / overfitting**）．

### 4.1.2　バイアス・バリアンスのトレードオフ

古典的統計学ではモデルの複雑度を上げると Bias が下がる代わりに Variance が増え，最適な複雑度が存在するという**トレードオフ**が成立する（$\text{Bias}^2 + \text{Variance}$ を最小化する「スイートスポット」）．

ただし，前章でも触れた**二重降下現象**（Belkin et al., 2019）は，このトレードオフがモデルが極めて過パラメータ化された領域では逆転しうることを示した：補間しきい値（interpolation threshold）を超えてモデルを大きくすると，汎化誤差が再び減少する第二の降下が現れる．深層学習の実用的な成功はこの第二の降下の領域で達成されている．

### 4.1.3　偏差・分散トレードオフとモデル選択

実用上のモデル選択では，以下の指針が有効である：

- 訓練誤差 ≪ テスト誤差（訓練誤差が低いがテスト誤差が高い）→ バリアンスが高い（過学習） → 正則化強化，データ増加，モデル簡略化
- 訓練誤差 ≈ テスト誤差，両者が高い → バイアスが高い（過小適合） → モデル複雑化，特徴量エンジニアリング

## 4.2　PAC 学習理論

### 4.2.1　一様収束と汎化誤差上界

第1章で経験リスク $\hat{R}(\theta)$ の最小化（ERM）を論じた際，真のリスクへの収束には**一様収束**が必要と述べた．Vapnik-Chervonenkis（VC）理論は，仮説クラス $\mathcal{F}$ の複雑度を**VC次元** $d_{\mathrm{VC}}$ で定量化し，汎化誤差上界を与える：

$$R(\hat{f}) \leq \hat{R}(\hat{f}) + O\left(\sqrt{\frac{d_{\mathrm{VC}} \log n + \log(1/\delta)}{n}}\right)$$

が少なくとも確率 $1 - \delta$ で成立する（PAC 学習上界）．

### 4.2.2　VC 次元

**VC 次元**は，仮説クラスが「粉砕（shatter）」できる最大の点集合のサイズとして定義される：仮説クラス $\mathcal{F}$ が $m$ 点の任意の二値ラベル付けを実現できるとき，$\mathcal{F}$ は $m$ 点を粉砕できると言い，$d_{\mathrm{VC}}(\mathcal{F}) \geq m$．

- 線形分類器（$d$ 次元）：$d_{\mathrm{VC}} = d + 1$
- $p$ パラメータの ReLU ネットワーク：$d_{\mathrm{VC}} = O(pL \log p)$（$L$：層数）

深層ネットワークは非常に大きな VC 次元を持つが，実際には PAC 上界よりずっと良い汎化性能を示す．これは VC 次元が最悪ケース解析であり，SGD の暗黙の正則化を考慮しないためである．

### 4.2.3　Rademacher 複雑度

より精密な汎化誤差上界を与える**Rademacher 複雑度**は，ランダムノイズラベルへの適合能力として定義される：

$$\hat{\mathfrak{R}}_n(\mathcal{F}) = \mathbb{E}_{\sigma}\left[\sup_{f \in \mathcal{F}} \frac{1}{n} \sum_{i=1}^{n} \sigma_i f(x_i)\right]$$

ここで $\sigma_i \in \{-1, +1\}$ は独立なラデマッハ変数．$\hat{\mathfrak{R}}_n(\mathcal{F})$ が小さいほど汎化誤差上界が小さくなる．

## 4.3　正則化技術

過学習への実用的な対処として，以下の正則化技術が広く用いられる．

### 4.3.1　$\ell_2$ 正則化（リッジ正則化・重み減衰）

損失関数にパラメータのノルムの二乗を加えることで，パラメータの大きな値を抑制する：

$$\mathcal{L}_{\mathrm{reg}}(\theta) = \mathcal{L}(\theta) + \frac{\lambda}{2} \|\theta\|_2^2$$

$\lambda > 0$ は正則化強度．勾配更新式は $\theta_{t+1} \leftarrow \theta_t(1 - \eta\lambda) - \eta \nabla_\theta \mathcal{L}$ となり，各ステップでパラメータが $(1-\eta\lambda)$ 倍に縮小されることから「重み減衰（weight decay）」とも呼ばれる（ただし AdamW の文脈では区別が必要，第3章参照）．

ベイズ的解釈：$\ell_2$ 正則化は等方ガウス事前分布 $p(\theta) = \mathcal{N}(0, \lambda^{-1}I)$ のもとでの MAP 推定に対応する．

### 4.3.2　$\ell_1$ 正則化（Lasso・スパース正則化）

$$\mathcal{L}_{\mathrm{reg}}(\theta) = \mathcal{L}(\theta) + \lambda \|\theta\|_1$$

$\ell_1$ 正則化は，最適解においてパラメータの多くが厳密に $0$ になる**スパース解**を誘導する．これは，ラプラス分布事前分布 $p(\theta) \propto \exp(-\lambda|\theta|)$ のもとでの MAP 推定に対応する．

特徴選択や解釈可能性が重要なタスクに有用だが，一般のニューラルネットワークの学習では $\ell_2$ の方が広く使われる．

### 4.3.3　Dropout

**Dropout**（Srivastava et al., 2014）は，各訓練ステップで各ニューロンを確率 $p$（通常 $0.5$）で独立にランダムに無効化する正則化手法である．**Inverted Dropout** と呼ばれる現代の標準実装では，生き残ったニューロンの値を $1/(1-p)$ でスケールアップする：

$$m_j \sim \text{Bernoulli}(1-p), \quad \tilde{h}_j^{(l)} = \frac{m_j}{1-p} \cdot h_j^{(l)}$$

ここで $m_j \in \{0, 1\}$ は各ニューロン $j$ の生存マスク（確率 $1-p$ で $1$）．このスケーリングにより訓練時の期待値 $\mathbb{E}[\tilde{h}_j] = h_j$ が保たれ，推論時は全ニューロンを使用しスケーリング不要（訓練時に既に補正済み）である．

**正則化効果の解釈：**
- アンサンブル解釈：$2^n$ 通りの異なるサブネットワークを同時に学習することに相当し，推論は近似的なアンサンブル
- 共適応の防止：ニューロンが互いに依存した表現を学ぶのを防ぐ
- ノイズ注入：入力に乗法的なノイズを加えることと等価（学習を正則化）

注意：Dropout は Batch Normalization と組み合わせると相互干渉が生じやすいことが知られている（Li et al., 2019）．Transformer では主に Attention と FFN の後に適用される．

### 4.3.4　バッチ正規化（Batch Normalization）

**バッチ正規化（Batch Normalization; BN）**（Ioffe & Szegedy, 2015）は，各ミニバッチ内での活性化の平均・分散を正規化する：

$$\hat{z}^{(l)} = \frac{z^{(l)} - \mu_{\mathcal{B}}}{\sqrt{\sigma_{\mathcal{B}}^2 + \varepsilon}}, \quad \tilde{z}^{(l)} = \gamma \odot \hat{z}^{(l)} + \beta$$

ここで $\mu_{\mathcal{B}} = \frac{1}{B}\sum_{i \in \mathcal{B}} z_i^{(l)}$，$\sigma_{\mathcal{B}}^2 = \frac{1}{B}\sum_{i \in \mathcal{B}} (z_i^{(l)} - \mu_{\mathcal{B}})^2$ はミニバッチ統計量，$\gamma, \beta$ は学習可能なスケール・シフトパラメータである．

**推論時：** ミニバッチ統計量の代わりに，訓練中に蓄積した指数移動平均 $\hat{\mu}$，$\hat{\sigma}^2$ を使用する．

**効果：**
- 活性化の分布を安定させ，高い学習率での学習を可能にする
- 重みの初期化への感度を低下させる
- 暗黙の正則化効果（ミニバッチノイズによる）

**制約：** バッチサイズが小さいと統計量の推定が不安定になる．

### 4.3.5　レイヤー正規化（Layer Normalization）

**レイヤー正規化（Layer Normalization; LN）**（Ba et al., 2016）は，BN の代替として特徴次元方向に正規化する：

$$\hat{z} = \frac{z - \mu_L}{\sqrt{\sigma_L^2 + \varepsilon}}, \quad \mu_L = \frac{1}{d}\sum_{j=1}^{d} z_j, \quad \sigma_L^2 = \frac{1}{d}\sum_{j=1}^{d}(z_j - \mu_L)^2$$

BN との違い：
- バッチ内のサンプル間ではなく，同一サンプルの特徴次元間で正規化
- バッチサイズに依存しないため，1サンプルでも適用可能
- 推論時に別途統計量を管理する必要がない

Transformer（第6章）や RNN での使用に適しており，現代の大規模モデルのデファクトスタンダードである．

### 4.3.6　データ拡張（Data Augmentation）

訓練データの量と多様性を人工的に増やす**データ拡張**は，特にモデルが訓練データに過適合しやすい小・中規模データセットで有効な正則化技術である：

- **画像データ：** ランダムクロップ・水平反転・色相変換・ランダム消去（Cutout），AutoAugment・RandAugment（拡張戦略の自動探索）
- **テキストデータ：** 同義語置換，逆翻訳（Back-Translation），EDA（Easy Data Augmentation）
- **ロボットデータ：** センサノイズ付加，剛体変換（第12章で詳述）

### 4.3.7　早期停止（Early Stopping）

バリデーション損失の改善が止まった時点で訓練を終了する**早期停止（Early Stopping）**は，暗黙的な正則化として機能する．バリデーションセットの性能を指標として訓練を打ち切ることで，訓練データへの過学習を防ぐ．実装は単純で，追加の計算コストがなく，他の正則化技術と自然に組み合わせられる．

## 4.4　モデル選択と交差検証

### 4.4.1　ホールドアウト法と交差検証

汎化性能を推定するための標準的な手法：

- **ホールドアウト（Hold-out）：** データを訓練・バリデーション・テストに固定分割．計算コストは低いが，分割方法に依存するバイアスが生じる
- **$k$-分割交差検証（$k$-fold Cross-Validation）：** データを $k$ 個に分割し，$k-1$ 個で訓練・$1$ 個で評価を $k$ 回繰り返す．汎化誤差の分散が小さい推定が得られるが，$k$ 倍の計算コスト
- **ネストした交差検証（Nested Cross-Validation）：** ハイパーパラメータ選択と汎化誤差推定を分離するための二重交差検証

### 4.4.2　正則化強度の選択

正則化強度 $\lambda$ はハイパーパラメータであり，バリデーションセット上の性能を基準に選択する．グリッドサーチ，ランダムサーチ，ベイズ最適化などが用いられる．

## まとめ

| 概念 | 内容 |
|------|------|
| バイアス・バリアンス | モデル複雑度のトレードオフ；二重降下現象により過パラメータ化では逆転 |
| PAC 学習 / VC 次元 | 有限サンプルでの汎化誤差上界の理論的保証 |
| $\ell_1/\ell_2$ 正則化 | パラメータのノルム抑制；$\ell_2$ はMAP推定のガウス事前分布に対応 |
| Dropout | ランダム無効化によるアンサンブル効果と共適応防止 |
| Batch / Layer Norm | 活性化の分布安定化；CNN に BN，Transformer に LN |
| データ拡張 | 訓練データの人工的多様化による過学習抑制 |
